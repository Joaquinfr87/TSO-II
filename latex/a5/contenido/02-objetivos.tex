\section{Objetivos del trabajo}

\subsection{Objetivo general}

Comprender el funcionamiento y la configuración de un servidor web (Nginx) y
de un servidor DHCP (Kea), así como su integración con los servicios de
resolución de nombres (DNS) y los demás servicios de la infraestructura de
red del proyecto \texttt{sudoers.lan}, en un entorno administrado con Debian.

\subsection{Objetivos específicos}

\begin{itemize}
  \item Comprender el funcionamiento del protocolo DHCP, incluido el proceso
        de negociación \textit{Discover–Offer–Request–Acknowledge} (DORA), la
        gestión de concesiones (leases) y las opciones que el servidor puede
        entregar a los clientes \cite{droms1997,rfc2131}.
  \item Instalar y configurar un servidor DHCP basado en Kea sobre Debian,
        definiendo la subred \texttt{192.168.0.0/24}, el ámbito de
        asignación dinámica para los equipos de usuario, las opciones de red
        (gateway, servidor DNS y dominio) y la desactivación del DHCP del
        router para evitar conflictos de asignación.
  \item Verificar la asignación automática de direcciones IP desde equipos
        clientes de la red, comprobando que cada uno recibe los parámetros de
        red configurables y que las concesiones quedan registradas en el
        servidor.
  \item Instalar y configurar de forma nativa el servidor web Nginx sobre
        Debian para alojar el sitio institucional del proyecto y servir como
        proxy inverso hacia los servicios internos.
  \item Implementar HTTPS con certificados SSL/TLS auto-firmados para la
        protección de las comunicaciones web.
  \item Configurar virtual hosts para múltiples subdominios del proyecto
        (\texttt{web.sudoers.lan}, \texttt{print.sudoers.lan},
        \texttt{files.sudoers.lan}, \texttt{portainer.sudoers.lan},
        \texttt{zabbix.sudoers.lan}).
  \item Configurar proxies inversos hacia los servicios internos del proyecto
        (CUPS, Filebrowser, Portainer y Zabbix) con soporte para WebSocket.
  \item Realizar pruebas de acceso web desde navegadores y verificación de
        los proxies inversos.
  \item Documentar el proceso completo de instalación, configuración y prueba
        de los servicios, incluyendo comandos, archivos de configuración y
        evidencias de cada paso.
\end{itemize}

# Instalación de Debian en el servidor

## Objetivo

Documentar el proceso para instalar Debian en un servidor de forma reproducible y mínima, dejando el sistema listo para la configuración posterior.

## Requisitos previos

- Acceso al hardware o a la máquina virtual donde se instalará Debian.
- Medio de instalación preparado.
- Información de red necesaria para la instalación, si aplica.
- Datos de acceso para el primer usuario administrador.

## Pasos

1. Preparar el medio de instalación según el entorno.
2. Arrancar la instalación y verificar la detección del hardware.
3. Seleccionar la configuración mínima adecuada para un servidor.
4. Definir particiones o esquema de almacenamiento.
5. Instalar el sistema base y los componentes necesarios.
6. Configurar el primer usuario y credenciales de acceso.
7. Revisar la configuración inicial del sistema.

## Verificación

- Confirmar que el sistema arranca correctamente.
- Validar que el usuario creado puede acceder al servidor.
- Revisar que la configuración de red y acceso básico está lista para la siguiente etapa de configuración.

> Esta guía debe completarse con los pasos reales, comandos y decisiones específicas del entorno.

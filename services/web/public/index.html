Stack técnico

Arquitectura del servidor

Todos los contenedores comparten la red interna tso-net y se comunican por nombre de servicio.

🔗 Red interna

  • Bridge network tso-net
  • Resolución DNS entre contenedores
  • Puertos mapeados al host sin conflictos
  • Dominio sudoers.local

💾 Persistencia

  • Volúmenes con nombre: dns_zones, mail_data
  • Datos sobreviven a recreaciones de contenedor
  • Configuraciones versionadas en el repositorio
  • Secretos locales en .env (gitignored)

🚀 Despliegue

  • docker compose up -d --build
  • Imágenes con versión fija (no latest)
  • Un solo docker-compose.yml como fuente de verdad
  • Reproducible en cualquier máquina con Docker
